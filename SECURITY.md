# Security · 安全报告

Use [private vulnerability reporting](https://github.com/IweirdoI/gitkit/security/advisories/new) for security issues. Include affected versions, impact and a minimal reproduction with credentials removed.

安全漏洞请通过 [GitHub 私有通道](https://github.com/IweirdoI/gitkit/security/advisories/new) 提交，附受影响版本、影响和已脱敏的最小复现。
